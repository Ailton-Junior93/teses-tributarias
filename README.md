# Teses Tributárias

Site das notas de teses tributárias, gerado com [Quartz](https://quartz.jzhao.xyz) e publicado pelo GitHub Pages.

- As notas ficam em `content/` (uma pasta por tributo; `content/index.md` é a página inicial).
- Para editar, altere ou adicione arquivos `.md` em `content/` — pelo próprio GitHub (botão ✏️) ou pelo Obsidian — e faça o commit na branch `main`.
- A cada commit, a rotina `.github/workflows/deploy.yml` recompila e republica o site automaticamente (aba **Actions**).
